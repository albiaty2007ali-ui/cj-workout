# CJ WORKOUT — Flask + Local-First Nutrition AI Chat

نسخة Python (Flask) + HTML/CSS/JS عادي، بدون أي اتصال API خارجي وقت التشغيل.
كل شيء فُحص فعليًا بسيناريوهات حقيقية (تسجيل، دخول، دفع، تفعيل، محادثة تغذية،
تسجيل وجبات، تحية بتوقيت بغداد) والتحقق من قاعدة البيانات مباشرة بعد كل خطوة.

## ✅ الميزات المُنجزة والمفحوصة

**الأساس (Phase 1):**
- Authentication حقيقي (تشفير كلمات مرور، نسيت كلمة المرور، CSRF، Rate Limiting)
- RBAC حقيقي (403 فوري لغير الأدمن)
- دفع يدوي Server-Verified (تحويل بطاقة + واتساب) مع تفعيل اشتراك ذرّي من الأدمن
- إيميلات حقيقية عبر Resend (ترحيب، تأكيد/رفض دفع)

**نظام التغذية الذكي (Local-First — بدون أي Nutrition API خارجي):**
- قاعدة بيانات محلية حقيقية: **43 صنف عراقي/عربي منسّق يدويًا + 395 صنف من
  USDA Foundation Foods** (بيانات مختبرية حقيقية، مو مخترعة) + 123 حصة حقيقية
  بأوزان بالغرام (كوب، ملعقة، حبة...).
- SQLite + FTS5 + Arabic Text Normalization للبحث السريع والمرن.
- **Quantity Resolver مستقل عن أي AI**: يفهم "بيضة"، "بيض"، "بيضتين"، "بيضتان"،
  "3 بيضات"، "200 غرام دجاج"، "صحن تمن متوسط" — بدون تخمين أي رقم.
- **Meal Confirmation Flow حقيقي**: يحلل → يسأل عن الكمية الناقصة → يحسب من
  القاعدة المحلية → يعرض للتأكيد → يسجل فقط بعد موافقة صريحة ("اي").
- **رسائل متعددة = وجبة وحدة**: المستخدم يكدر يرسل "فطرت بيض" ثم "بيضتين" ثم
  "ويا خبز" — كلها تتجمع بوجبة وحدة، ما تُحتسب كذا وجبات من رصيده المجاني.
- **6 وجبات مجانية Server-Side بالكامل** + Premium Lock عند المحاولة السابعة.
- **تعويض ذكي**: وجبة دسمة → نصيحة توازن بدون لوم؛ لا يقول أبدًا "متوقف عن الأكل".
- **نظام الوقت العراقي (Asia/Baghdad)**: تحية مختلفة حسب الفترة (صباح/ظهر/مساء/
  ليل متأخر)، ولا يسأل عن نفس الوجبة مرتين إذا انسألت أو انسجلت أصلًا بنفس اليوم
  (`MealStatus`: not_started → asked → logged).
- **قاعدة نصائح غذائية حقيقية (~28 نصيحة، 12 تصنيف)**: تُختار حسب حالة المستخدم
  الفعلية (بروتين قليل، تجاوز سعرات، قرب من الهدف...) لا عشوائيًا بالكامل، ولا
  تتكرر على نفس المستخدم (تتبع عبر `ShownTip`).
- مساعد طبخ تفاعلي (Context-Aware): يتذكر الوصفة والخطوة الحالية.

## 🚀 التشغيل محليًا

```bash
python3 -m venv venv
source venv/bin/activate        # ويندوز: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
python3 -c "import secrets; print(secrets.token_hex(32))"   # الصق الناتج بمكان SECRET_KEY بـ .env

python3 app.py
```

افتح: **http://127.0.0.1:5000**

قاعدة بيانات الأكل (`data/database/foods.sqlite`) **مبنية مسبقًا وجاهزة** —
ما تحتاج تشغّل استيراد إضافي إلا إذا حبيت تضيف بيانات جديدة:

```bash
python3 scripts/import_foods.py --reset --seed              # يعيد بناء القاعدة من الصفر (البيانات العراقية فقط)
python3 scripts/import_foods.py --usda data/raw/usda        # يضيف بيانات USDA (يحتاج تحمّل الملفات الخام أولًا)
```

### تعيين أول حساب أدمن
```bash
python3 make_admin.py your-email@example.com
```

```bash
gunicorn -w 4 -b 0.0.0.0:8000 "app:create_app()"
```
